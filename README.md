# 텍스트 발췌기

AI 채팅·롤플레이 글을 붙여 넣고 꾸며서 **이미지나 PDF 로 저장**하는 웹앱입니다.
대화 백업이나 공유용 발췌 이미지를 만들 때 씁니다.

**바로 쓰기 → https://e-e1ght.github.io/text-extract/**

- 설치·가입 없이 브라우저에서 바로 동작합니다.
- 서버가 없어 본문·이미지가 어디로도 전송되지 않습니다. 작업 내용은 이 브라우저에만 저장됩니다.

## 쓰는 법

1. 미리보기 영역에 글을 붙여 넣습니다. 대사·서술이 자동으로 구분되어 색이 입혀집니다.
2. 왼쪽 도구 막대에서 제목, 글꼴, 배경, 여백 등을 고릅니다.
3. 글자 일부를 바꾸려면 드래그로 고른 뒤 오른쪽 위 **편집** 단추로 패널을 엽니다.
4. **저장 · 설정** 탭에서 이미지(PNG·JPG)나 PDF 로 저장합니다.

화면 오른쪽 위 **?** 단추를 누르면 기능을 하나씩 짚어 주는 도움말이 열립니다.

## 주요 기능

### 본문 자동 인식
- `"…"` `“…”` `「…」` `『…』` 안은 **대사** (줄바꿈이 있어도 하나로 인식)
- `*…*` 안은 **강조 서술**, 나머지는 **서술**
- 캐릭터는 말풍선 탭에서 추가하거나, 본문에서 이름을 드래그해 편집 패널의 **캐릭터** 단추로 지정
- `*` 기호 감추기, 괄호 안을 작은 회색 글씨로 표시하기
- 붙여 넣을 때 빈 줄 정리

### 편집 패널 (드래그한 글에 적용)
- 볼드 · 이탤릭 · 밑줄 · 취소선 · 형광펜 · 세로선
- 글꼴 · 글자 크기 · 글자 색 (색 코드 입력, 최근 사용한 색)
- 대사·서술 등 **역할 전체**의 색을 한 번에 바꾸거나, 고른 부분만 바꾸기
- **말풍선 / 대본** 으로 묶기 — 인물을 고르면 그 캐릭터의 색·프로필이 붙음
- **가리기** — 검은 막대 또는 흐림 (글은 지우지 않고 덮기만 함)
- 제목·부제목·제작자 줄도 드래그해서 색·크기 변경

### 도구 막대

| 탭 | 하는 일 |
| --- | --- |
| 제목 · 제작자 | 제목·부제목·제작자 입력, 본문 위/아래 위치, 정렬, 간격 |
| 본문 | 글꼴(웹 글꼴 + 내 글꼴 파일 올리기), 굵기, 서술·대사 크기, 자간, 행간, 장평, 문단 간격, 들여쓰기, 정렬, 줄바꿈, 구분선, 페이지 나눔 |
| 대사 · 서술 | 대사/서술 자동 구분, 대사·강조 기울임, `*` 기호 감추기, 괄호 안 작게 |
| 말풍선 · 캐릭터 | 캐릭터별 이름·대사·말풍선 색과 프로필 이미지, 말풍선 모양 |
| 이미지 | 배경(단색 · 그라데이션 · 이미지/GIF · 패턴 · 아스키 아트), 오버레이, 본문 속 이미지, 스티커, 이미지 슬롯 |
| 내지 옵션 | 상하좌우 여백, 이미지 너비·비율, 세로 정렬, 페이지 테두리 |
| 저장 · 설정 | 이미지/PDF 저장, 클립보드 복사, 서식 저장·불러오기, 초기화, 도구 위치 |

### 배경과 이미지
- 배경 패턴: 점 · 체크 · 별 · 물방울 · 타탄 · 물결 칸 (색·크기·간격·각도 조절, 타탄은 두 색)
- 아스키 아트: 그림을 글자로 바꿔 배경에 깔기
- 배경·이미지는 미리보기에서 끌어서 위치를, 휠로 크기를 조절
- 스티커: 본문 위에 얹는 이미지 (이동 · 크기 · 회전 · 외곽선 · 그림자)
- 이미지 슬롯: 본문 위·아래·왼쪽·오른쪽에 붙는 이미지 칸

### 저장
- PNG · JPG · PDF, 1~4배 해상도, 파일 이름 지정
- **여러 장으로 나누기**: 긴 글을 1:1, 4:5, 9:16 등 같은 비율의 여러 장으로 (문단은 자르지 않음)
- 직접 넣은 페이지 나눔 기준으로 나눠 저장, 쪽 번호 넣기
- 이미지를 클립보드로 복사

### 작업 보관
- 본문과 서식은 새로고침하거나 나중에 다시 와도 그대로 남습니다.
- 되돌리기 / 다시 실행 (Ctrl+Z / Ctrl+Shift+Z) — 본문과 서식을 함께 되돌림
- 서식에 이름을 붙여 이 브라우저에 저장, 서식 파일로 내보내기·불러오기 (공유용)
- 라이트 / 다크 화면, 도구 막대 왼쪽/오른쪽 위치

## 알아 둘 점
- GIF 배경은 미리보기에서만 움직이고, 저장하면 한 장면으로 고정됩니다.
- 작업 내용은 브라우저에만 있으니, 브라우저 데이터를 지우면 함께 사라집니다. 아끼는 서식은 파일로 내보내 두세요.

## 개발

React 18 + TypeScript + Vite. 이미지 저장은 `html-to-image`, PDF 는 `jspdf`.

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 정적 빌드 → dist/
npm run preview  # 빌드 결과 확인
```

`main` 브랜치에 push 하면 GitHub Actions 가 GitHub Pages 로 배포합니다 (`.github/workflows/deploy.yml`).
빌드 경로는 `/text-extract/` 로 잡혀 있고, `VITE_BASE` 환경변수로 바꿀 수 있습니다.

코드 구조, 설계 결정, 까다로웠던 버그의 원인과 해결은 [`DEVELOPMENT.md`](DEVELOPMENT.md) 에 정리해 두었습니다.
