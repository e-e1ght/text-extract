# 텍스트 발췌 생성기 제작

본 세션에서는 텍스트를 입력한 뒤, 이미지로 출력하는 '발췌기' 제작을 목적으로 한다.
해당 사이트는 AI 채팅을 향유하는 이용자들의 대화 백업 or 공유를 위해 제작되며, 발췌기에서는 각종 텍스트 편집 옵션과 편의 기능을 지원한다.

기본적으로 작업물 저장 경로는 연결된 github 저장소(zero-hyaku/text-extract)를 사용한다.

## 주요 기능

[1] 본문 편집 옵션 & 결과물 미리보기

* 본문 편집 옵션: 좌측 혹은 우측 사이드바에 위치한다. 이때 사이드바의 위치는 옵션으로 분리해 위치를 선택할 수 있도록 한다.
* 결과물 미리보기:
  - 본문 옵션에서 선택한 옵션과 본문을 미리 볼 수 있는 영역을 포함한다. 이때 본문 옵션에서 선택한 모든 항목이 반영되어야 한다.
  - 이때 별도로 너비를 지정하지 않아도 기본적으로 제공되는 이미지 영역이 존재해야 한다. 사용자가 이미지 크기를 지정하지 않아도 본문 텍스트에 따라서 이미지 영역이 유동적으로 늘어날 수 있도록 한다.

[2] 드래그로 텍스트 수정 가능

* 기본적으로 편집할 텍스트는 '결과물 미리보기가 출력되는 창'에 붙여넣을 수 있어야 한다.
* 본문 편집 옵션은 (1) 사이드바 (2) 수정을 원하는 텍스트를 드래그할 경우 팝업, 두 방식으로 표시되어야 한다.

## 추가 기능

[1] 본문 편집 옵션 (텍스트)

* 볼드, 이탤릭, 밑줄, 취소선, 하이라이트(컬러 선택 가능)
* 자간, 행간, 장평, 문단 간격, 텍스트 크기 조절
* 정렬 및 줄바꿈 (단어 단위, 글자 단위)
* 텍스트 컬러(캐릭터 이름, 서술, 대사 컬러 분리), 배경 컬러(기본적으로 단색. 옵션으로 그라데이션, 이미지, gif, 영상 지원)
* 대사 / 서술 분리
  - "" 내부의 텍스트는 대사로 인식한다. 대사는 "" 내부의 줄바꿈까지 포함하여 인식해야 한다.
  - "" 내부에 있지 않거나, ** 내부에 있거나, 별도의 특수문자로 감싸여 있지 않는 텍스트는 서술로 인식한다.\
* 캐릭터 이름과 대사 표시
* 제목, 부제목, 제작자 표시 기능

[2] 본문 편집 옵션 (이미지)

* 텍스트가 입력되는 영역의 크기 조절 기능이 포함되어야 한다. 아래 기능을 포함한다:
  - 상 / 하 / 좌 / 우 여백 지정
  - 이미지 영역 전체 비율 지정 (가로/세로)
  - 모든 여백 수정에는 텍스트 입력란과 슬라이더를 함께 포함한다.

[3] 이미지 저장 기능

* 편집을 완료한 본문은 별도의 이미지로 저장되어야 한다.
* 이미지 외에도 pdf 저장 옵션을 지원한다.

[4] 테마 기능

* 메신저 테마: 입력된 본문에서 대사와 서술을 인식한 뒤, 대사를 메신저 형태의 말풍선으로 변경한다. 이때 대사 영역에는 (1) 캐릭터 프로필 이미지(사진을 입력하지 않을 경우 캐릭터 이름 컬러와 동일하게 출력) (2) 캐릭터 이름 (3) 대사가 포함된다.

[5] 서식 저장 기능

* 현재까지 사용자가 저장한 옵션은 해당 사이트 새로고침 or 다음에 방문해도 저장되도록 한다.
* 그 외에도 서식 공유를 위하여 사용자가 지정한 본문 편집 옵션 백업용 파일 저장/불러오기 기능을 추가한다.
